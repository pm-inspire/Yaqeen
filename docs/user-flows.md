# Updated User Flow Diagrams (Textual)

## Flow A: Discovery & Navigation

1. الرئيسية  
2. تحديد المرحلة والصف الدراسي  
3. ترتيب حسب  
4. فلتر بحث  

Goal: speed up course discovery with fewer taps and clearer filter intent.

## Flow B: Course Engagement

5. تفاصيل الدورة لغير المشتركين  
6. تسجيل الدخول  
7. مشاركة الدورة  
8. الاشتراك في الفترة - الخطوة الأولى  
9. الاشتراك في الفترة - الخطوة الثانية  
10. تقييم الدورة والمعلم  

Goal: increase conversion from preview to paid enrollment.

## Flow C: Search Experience

11. نتائج البحث  
12. البحث بدون نتائج (لا يوجد بيانات + CTA)  

Goal: reduce dead-end exits using corrective guidance.

## Flow D: User Dashboard

13. المفضلة (لا يوجد بيانات + CTA when empty)  
14. تفاصيل الدورة للمشتركين  
15. شروحاتي  

Goal: improve retention with easier content continuity.

## Flow E: Community & Content

16. ساحات النقاش  
17. تعليقات منشور  
18. شروحات الوحدة  
19. تفاصيل الشرح  

Goal: improve engagement and peer-learning interactions.

## Flow F: Additional Features

20. مزيد من التفاصيل للدورة  
21. المحادثة  
22. المزيد  
23. طلباتي  
24. احصل على مساعدة  
25. من نحن  
26. تسجيل الخروج  

Goal: reduce support burden through clear secondary journeys.

## Core Educational Breadcrumb

`دورة -> فترة -> معلم -> وحدة -> درس`

This breadcrumb hierarchy should be visible in relevant detail and lesson screens.
